# Checkpoint model

Bobot checkpoint tidak disertakan dalam repositori publik ini. Untuk
menjalankan konfigurasi Docker yang tersedia, tempatkan checkpoint T5-small
yang kompatibel di `checkpoints/t5-small-unhas-picard-noalias-20260917/`.
Pastikan tokenizer berasal dari checkpoint yang sama, lalu cocokkan berkas
dan hash dengan `docs/model_checksums.sha256` serta kontrak pada
`docs/model_training_contract.json`.

# Database evaluasi

Database SQLite mentah tidak disertakan karena dapat berisi data pribadi.
Untuk menjalankan layanan, sediakan salinan yang penggunaannya diizinkan di
`database/neosia/neosia.sqlite`. Gunakan skema dan isi yang sama untuk kedua
server saat membandingkan hasil. Jangan menambahkan berkas `.sqlite` ke
repositori publik tanpa izin publikasi dan pemeriksaan privasi.
